# ZX Spectrum 48K

The non-paged 48K build: 1-bit mono or classic 8x8-attribute colour art. It shares the story engine with the
[128K target](zx128.md), but has no NIRVANA+ engine, no bank switching, no snapshot output and **no AY music**.

- **Black and white:** on by default, rendering the picture as a dithered 1-bit band. The scene title, text and menu
  options keep the Game tab's colours (and `title_ink:`), the same as on the 128K; `mono: off` uses classic Spectrum
  8x8 attribute-colour art instead.
- **Display:** a picture band, 256 x `8 * art_rows` pixels, above the text. With Black and white the band is 1-bit
  white-on-black; otherwise each 8x8 cell gets one ink and one paper colour plus the shared BRIGHT bit (the classic
  attribute-clash look, up to 15 colours). `art_rows` is the `## zx48` option (even 8..16, default 10) and is
  independent of the 128K band;
  changing it frees or consumes text rows without touching `## zx128`. A legacy shared `# Game art_lines` value is
  copied into `zx48_art_rows` on load when the 48K block has no `art_rows`.
- **Dithering:** the `## zx48` system block chooses `dither:` from the full list (`bayer2`/`bayer4`/`bayer8`/`noise`/
  `floyd`/`atkinson`/`jarvis`/`stucki`/`sierra`). Classic colour art dithers between each 8x8 cell's ink and paper;
  `off` keeps the hard nearest-colour snap. With Black and white on, `off` (the default) becomes the ordered `bayer2`
  scheme for the 1-bit band, because a hard threshold would throw away every mid-tone. Coarser ordered schemes
  compress best; error diffusion uses more of the main-image budget. `margin:` adds N 8x8-cell borders on the left
  and right; the 48K border is always black.
- **Layout:** title row 0, art rows 1..`art_rows`, text below, row 23 inventory, or the `menu: popup` dialog.
- **Storage:** compressed scene blobs live in the lower-RAM flat store at `0x6000` and are read at startup by
  `src/zx/loader48.asm` with the ROM `LD-BYTES` routine. The flat store is 7,168 B, leaving the top 1 KB of lower RAM
  for the stack (`REGISTER_SP` = `0x7FFE`). Compressed art and the inventory blob are compiled into the main image
  (art is too large for the flat store); removing the NIRVANA+ engine reservation lets the main image use
  `0x8000-0xFFFF` (32,768 B).
- **No NIRVANA+:** `src/zx/plat_zx.c` draws the decoded band straight into the Spectrum bitmap under `ZX48` (and
  copies the 8x8 attributes for colour art), with no attribute-racing ISR or tile map. `tools/build.py` skips
  building/linking/merging `nirvanap.lib` for this target.
- **Music:** the 48K has no AY sound chip. Songs declared in `game.md` are ignored by this target; the Systems card
  explains this and validation emits a warning. Use the 128K target for music.
- **Build:** `zcc +zx` with `-DZX48`, then `z88dk-appmake` and `tools/make_tap48.py`. Output is `<slug>-48k.tap`.
- **Emulator:** JSSpeccy in 48K mode. The Emulator tab lists this target only when **ZX Spectrum 48K** is ticked in
  the Systems tab; the option serves `<slug>-48k.tap` and reports "not built yet" until that artifact exists.
  On a touch device the tab draws the same on-screen D-pad/ENTER/SPACE/P pad as the 128K entry.
  `tools/spectrum.py run <tap> 48k` starts ZEsarUX in 48K mode for headless checks.
- **Editor preview:** the Art tab renders a separate 48K preview (`?target=zx48`) alongside the 128K NIRVANA+
  preview, using the same crop and conversion settings; it follows the Black and white checkbox (mono or classic
  colour).

## Memory map (48K)

| Region | Contents |
|---|---|
| `0x4000-0x5AFF` | screen bitmap + attributes |
| `0x5B00-0x5FFF` | ROM system variables (untouched) |
| `0x6000-0x7BFF` | flat compressed **scene** store (`FLAT_DATA_SIZE` = 7,168 B) |
| `0x7C00-0x7FFF` | stack (1 KB, `REGISTER_SP` = `0x7FFE`) |
| `0x8000-0xFFFF` | linked main image: code, `_scene_ws`, `_art_ws`, directories, compressed **art** and **inventory** (max 32,768 B) |

The build fails instead of producing a broken TAP when either budget is exceeded:

- `48K build does not fit: compressed scene data is N B but only 7168 B fits at 0x6000-0x7BFF …`
- `48K build does not fit: main image is N B but only 32768 B fits at 0x8000-0xFFFF …`

To recover space shorten scene text/options (the flat store), or lower `## zx48 art_rows`, remove/merge arts or shorten
item descriptions (the main image). Art totals scale roughly: 8 rows ≈ 8 KB, 10 ≈ 11 KB, 12 ≈ 13 KB, 16 ≈ 18 KB
for a ten-art mono game (classic-colour art adds 32 attribute bytes per character row). Use the 128K target for
NIRVANA+ art and music.

Key files: `src/zx/loader48.asm`, `src/zx/plat_zx.c` (`ZX48` art renderer), `tools/gen_scenes.py` (`SCENE_FLAT`),
`tools/make_tap48.py`, `tools/targets/zx48.py`.
