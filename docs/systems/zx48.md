# ZX Spectrum 48K

The non-paged NIRVANA+ build for 48K Spectrums. It shares the story engine and art conversion with the
[128K target](zx128.md), but has no bank switching, no snapshot output and **no AY music**.

- **Display:** the same NIRVANA+ bicolor band, 256 x `8 * art_rows` pixels, 16 Spectrum colours. `art_rows` is shared
  with the 128K target (`# Game art_lines`, even 8..16, default 10).
- **Layout:** identical to the 128K target: title row 0, art rows 1..`art_rows`, text below, row 23 inventory, or the
  `menu: popup` dialog.
- **Storage:** every compressed art/scene/inventory blob lives in one flat resident block at `0x6000`. The block is
  read at startup by `src/zx/loader48.asm` with the ROM `LD-BYTES` routine; `plat_load()` decodes from
  `FLAT_DATA_ADDR + off + 2` with `port_unpack()` (no paging).
- **Music:** the 48K has no AY sound chip. Songs declared in `game.md` are ignored by this target; the Systems card
  explains this and validation emits a warning. Use the 128K target for music.
- **Build:** `zcc +zx` with `-DZX48`, the vendored NIRVANA+ library, then `z88dk-appmake` and
  `tools/make_tap48.py`. Output is `<slug>-48k.tap`.
- **Emulator:** JSSpeccy in 48K mode. The Emulator tab lists this target only when **ZX Spectrum 48K** is ticked in
  the Systems tab; the option serves `<slug>-48k.tap` and reports "not built yet" until that artifact exists.
  `tools/spectrum.py run <tap> 48k` starts ZEsarUX in 48K mode for headless checks.

## Memory map (48K)

| Region | Contents |
|---|---|
| `0x4000-0x5AFF` | screen bitmap + attributes |
| `0x5B00-0x5FFF` | ROM system variables (untouched) |
| `0x6000-0x7BFF` | flat compressed art/scene/inventory store (`FLAT_DATA_SIZE` = 7,168 B) |
| `0x7C00-0x7FFF` | stack (1 KB, `REGISTER_SP` = `0x7FFE`) |
| `0x8000-0xDC03` | linked main image: code, `_scene_ws`, `_art_ws`, directories (max 23,555 B) |
| `0xDC03-...` | vendored NIRVANA+ engine (fixed org) |

The build fails instead of producing a broken TAP when either budget is exceeded:

- `48K build does not fit: compressed art/scene/inventory data is N B but only 7168 B fits at 0x6000-0x7BFF …`
- `48K build does not fit: main image is N B but only 23555 B fits at 0x8000-0xDC03 …`

To recover space use a shorter `art_rows`, remove or merge arts (repoint a scene's `art:`), shorten scene text and item
descriptions, or build the 128K target instead.

Key files: `src/zx/loader48.asm`, `src/zx/plat_zx.c` (flat `plat_load`), `tools/gen_scenes.py` (`SCENE_FLAT`),
`tools/make_tap48.py`, `tools/targets/zx48.py`.
