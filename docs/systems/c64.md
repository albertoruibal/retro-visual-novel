# Commodore 64

- **Display:** 40 x 25 characters. The VIC-II runs in multicolor character mode: the scene title is on row 0, the art
  band occupies rows 1..`art_rows`, and the text pane runs from row `art_rows + 1` through row 24. `art_rows` is 8, 10
  or 12 (default 8). Text uses the shared CC0 8x8 font as hi-res glyphs; art cells are 4x8 multicolor
  characters.
  The options and held items live in the `SPACE`-key action dialog (there is no permanent inventory row) and a long
  scene body or item description scrolls with the cursor keys/WASD.
- **Colours:** the C64's fixed 16-colour palette. Text foregrounds are limited to the first eight colours because
  multicolor character mode uses colour-RAM bit 3 as its mode flag; `text_bg:` may be any of the 16 and is the global
  `$D021` background. `text_ink:` colours body text and `highlight_ink:` every selection; dim tokens approximate the
  base colour. The art fixes `$D021` to `text_bg` and chooses `$D022`/`$D023` per art, with one extra per-cell colour
  from 0..7.
- **Charset/art:** `tools/c64art.py` fits the source to a 160 x `8 * art_rows` logical band (the preview is rendered
  at 320 physical pixels because multicolor pixels are twice as wide), quantises it to the C64 palette and assigns
  each 4x8 cell four colours. Patterns are deduplicated into at most 160 art tiles at charset indices 96..255; the
  first 96 entries are the text glyphs. `margin:` adds N 8x8-cell borders on the left and right, filled with
  `text_bg`; the picture is scaled to the inner width with its aspect preserved. The art blob is
  `[u8 ntiles][u8 color22][u8 color23][tiles][map][colors]`, ZX0-compressed in the `.prg`.
- **Text:** `tools/gen_port.py --c64` emits `build/port_font8.h` from the shared Pixel Operator font (with the accent
  slots), bit-reversed for the VIC-II's MSB-first patterns. `src/c64/plat_c64.c` copies it into the charset at
  `$A000` and draws text through screen RAM (`$A800`) and colour RAM (`$D800`).
- **Storage/memory:** there is no banking. Scene/inventory blobs and the compressed art are resident in the `.prg`
  and decoded by `src/6502/zx0.c`, a C port of the standard ZX0 decoder. The linker config (`src/c64/c64.cfg`) reserves
  `$A000-$A7FF` for the charset and `$A800-$ABFF` for screen RAM, puts BSS at `$AC00-$C7FF` and leaves the C stack at
  `$C800-$CFFF` (the crt0 starts it at `$D000`). VIC bank 2 is selected through CIA2. The loaded image must end below
  `$A000`; the target checks the `.prg` size.
- **Controls:** cursor keys or `W` `A` `S` `D` move; `RETURN` confirms; `SPACE` opens/closes the action dialog. `P`
  pauses/resumes music when a C64 music player is added.
- **Sound:** not implemented yet. The C64 build ignores the game's `songs:`/`music:` settings; other targets still
  play them.
- **Build:** `cl65 -t c64 -C c64.cfg -Oirs ...`, output `<slug>.prg`; cc65 is required (z88dk has no C64 target). The
  editor Docker image contains cc65; on a desktop install cc65 and point the **Build toolchain** settings card at it.
- **Emulator:** the editor's Emulator tab runs the `.prg` in a pinned EmulatorJS build of VICE x64sc (the core embeds
  the C64 ROMs). It forwards the physical keyboard, so the game's cursor/WASD/Return/Space keys work after clicking
  the picture. You can also run it with desktop VICE (`x64sc <slug>.prg`, or drag it onto a VICE window). The file
  also runs on a real C64 via `LOAD"*",8,1`.
- **Limitations:** no boot-password screen. Text colour tokens are limited to the first eight C64 colours, and the
  multicolor art is 160 logical pixels wide.

Key files: `tools/targets/c64.py`, `tools/c64art.py`, `src/c64/plat_c64.c`, `src/c64/c64_hw.s`, `src/c64/c64.cfg`,
`src/6502/zx0.c`, `tools/gen_port.py`.
