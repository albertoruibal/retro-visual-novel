# Amstrad CPC 464

The CPC 464 is the 64K, cassette-based member of the CPC family. It has no
extra 16K RAM banks, so it cannot use the CPC 6128's paged-art layout. This
target keeps the story, font and engine resident and stores the compressed
art/song blobs in `GAME.Bn` files on the disk, loading one at a time through
AMSDOS with `src/cpc/cpc_disk.asm`. It therefore needs a disk drive (for
example a DDI-1); it is not a cassette-only build.

- **Display:** Same Gate Array Modes 0/1/2 and text layout as the [CPC
  6128](cpc.md). The default is Mode 1 (320x200, four monochrome shades);
  Modes 0 and 2 are selectable. Mode 0 always uses the under-art `SPACE`
  action dialog. Modes 1/2 keep the pinned options/inventory unless the
  system sets `menu: popup`.
- **Art:** The same converter as the 6128 (`tools/cpcart.py`), with `art_rows`
  defaulting to 8 for the 464. Art is compressed and packed into the disk bank
  files at build time; the runtime opens the file, skips to the blob, reads it
  into a small resident buffer and ZX0-decodes it straight into screen memory.
  The first visit to a new picture pauses while the disk is read.
- **Storage:** The engine, scene/inventory blobs, font and the art load buffer
  are resident below the fixed workspaces at `CPC_WS_BASE`. Art and songs live
  in the `GAME.B4..B7` (and optional `GAME.B2`) files on the same `.dsk`; the
  CRT loader is disabled (`CRT_DISABLELOADER=1`) so the 464 never tries to page
  those files into nonexistent banks. The map guard verifies the resident
  image ends below the workspaces. If it does not fit, lower
  `cpc464_art_rows`, shorten the game, or build the 6128 target.
- **Sound:** `# Game songs:` / per-scene `music:` PT3 modules play through the
  AY/VT2 player. The compressed module is read from its disk bank file into the
  resident song workspace when the song changes. Press `P` to toggle music.
- **Options:** `mode`, `columns`, `art_rows`, and `menu: popup` (Modes 1/2;
  Mode 0 always uses the dialog). The dialog key is `SPACE`; `ENTER`/fire
  confirms.
- **Controls:** arrow keys or W/A/S/D move the cursor; Enter or the joystick
  fire button chooses (Space also chooses on the pinned Modes 1/2 layout). `P`
  toggles music. In Mode 0 up/down scrolls long scene text (left/right moves
  between highlighted words) and `SPACE` opens/closes the action dialog.
- **Build:** `zcc +cpc -subtype=dsk` with the CRT loader disabled. The internal
  file name is the fixed 8.3 `GAME` so emulators can auto-run it. Output
  `<slug>-cpc464.dsk`.
- **Emulator:** CPCJS/Caprice32 WASM (`emulator/cpc?model=464`), configured for
  a 64K CPC 464 with AMSDOS, auto-running `GAME`.

Key files: `tools/targets/cpc464.py`, `tools/cpcart.py`, `src/cpc/plat_cpc.c`,
`src/cpc/cpc_disk.asm`, `src/cpc/cpc_paging.asm`, `src/cpc/font8_4bpp.h`,
`build/port_ws.asm` and `src/portable/core/music.c`.
